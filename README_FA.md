# رزرویار سلف گیلان — پروژه اندروید

این پروژه یک پوسته Android WebView برای بازکردن سامانه `food.guilan.ac.ir` و نمایش ابزار پایش در همان صفحه است.

## ساخت APK در ویندوز (بدون اجرای دستورهای پیچیده)
1. Android Studio را نصب و اجرا کنید.
2. فایل ZIP را Extract کنید.
3. در Android Studio گزینه **Open** را بزنید و پوشه `SamadRoo_App` را انتخاب کنید (خود فایل ZIP را انتخاب نکنید).
4. اگر پیام نصب SDK یا Build Tools آمد، نصب را تأیید کنید؛ پروژه به **Android SDK Platform 35** نیاز دارد.
5. در **File > Settings > Build, Execution, Deployment > Build Tools > Gradle**، گزینه **Gradle JDK** را روی JDK 17 یا نسخه سازگار Android Studio بگذارید.
6. صبر کنید Gradle Sync کامل شود. اگر Android Studio پیشنهاد نصب/دانلود Gradle کرد، تأیید کنید.
7. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** را انتخاب کنید.
8. پس از پایان، روی **locate** بزنید. فایل خروجی معمولاً در مسیر `app/build/outputs/apk/debug/app-debug.apk` است. آن را به گوشی منتقل و نصب کنید.

برای نصب APK روی گوشی، ممکن است لازم باشد اجازه **Install unknown apps / نصب برنامه‌های ناشناس** را برای برنامه‌ای که فایل را باز می‌کند فعال کنید.

## استفاده
وارد سامانه شوید، صفحه منوی غذا را باز کنید، غذاها را از پنل داخل صفحه انتخاب کنید و «شروع پایش» را از نوار بالای برنامه بزنید. فاصله رفرش کامل حداقل ۳ ثانیه است؛ مقدار پیش‌فرض ۵ ثانیه است.

## ملاحظات
- این بسته سورس پروژه Android Studio است، نه APK آماده.
- این بسته سورس آمادهٔ ساخت است؛ APK تا زمان اجرای Build در Android Studio تولید نمی‌شود.
- منطق صفحه با DOM سامانه کار می‌کند و هنوز روی حساب واقعی/سامانه زنده آزمایش نشده است.
- بعضی سامانه‌ها ورود یا محتوا را در فریم‌های cross-origin بارگذاری می‌کنند؛ اگر فرم رزرو در چنین فریمی باشد، WebView ممکن است به آن دسترسی نداشته باشد.
- Android ممکن است زمان‌بندی جاوااسکریپت را در پس‌زمینه محدود کند. برای پایش، برنامه را باز و صفحه را در پیش‌زمینه نگه دارید.
- قفل یک‌باره در SharedPreferences ذخیره می‌شود؛ فقط پس از بررسی وضعیت رزرو آن را پاک کنید.
- برنامه رمز عبور را جداگانه دریافت نمی‌کند؛ ورود در خود صفحه رسمی انجام می‌شود.

## ساخت APK آنلاین با GitHub Actions (بدون Android Studio)

1. این ZIP را در رایانه از حالت فشرده خارج کنید.
2. در GitHub یک حساب بسازید یا وارد شوید و یک مخزن جدید (New repository) ایجاد کنید.
3. فایل‌ها و پوشه‌های داخل ZIP را در ریشه مخزن بارگذاری کنید؛ پوشه `SamadRoo_App` باید در ریشه مخزن دیده شود.
4. وارد زبانه **Actions** شوید. اگر GitHub گزینه فعال‌سازی Actions را نشان داد، آن را فعال کنید.
5. از فهرست سمت چپ، **Build Android APK** را انتخاب و روی **Run workflow** بزنید. (با بارگذاری روی شاخه `main` نیز ساخت خودکار اجرا می‌شود.)
6. پس از پایان موفق اجرا، همان اجرای workflow را باز کنید و در بخش **Artifacts** فایل `SamadRoo-debug-apk` را دانلود کنید.
7. ZIP دانلودشده را باز کنید؛ فایل `app-debug.apk` داخل آن است. آن را به گوشی منتقل و نصب کنید.

نکته: این workflow نسخه Debug و امضانشده برای نصب و آزمایش شخصی می‌سازد، نه نسخه انتشار فروشگاهی. برای انتشار عمومی باید APK/AAB امضاشده تولید شود. ساخت موفق نیز به معنی آزمایش عملکرد روی سامانه واقعی نیست.
